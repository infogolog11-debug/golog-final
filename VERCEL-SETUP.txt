# ============================================================
# 🔗 إعدادات Google OAuth في Google Cloud Console
# ============================================================
# 1. افتح: https://console.cloud.google.com/apis/credentials
# 2. أنشئ OAuth Client ID من نوع Web application
# 3. Authorized redirect URIs → أضف:
#
#        https://golog-final.vercel.app/api/auth/google/callback
#
#    (أبدل golog-final.vercel.app بدومينك الفعلي إن كنت تستخدم دومين مخصص)
#
# 4. انسخ Client ID و Client Secret إلى متغيرات Vercel أعلاه.

# ============================================================
# 🤖 إعداد ربط بوت تيليجرام بـ Webhook
# ============================================================
# بعد النشر الأولي، شغّل محلياً:
#
#   npm run register-telegram-webhook --workspace=@golog/api-server
#
# أو استخدم الأمر مباشرة (استبدل بالTOKEN والرابط):
#
#   curl -X POST "https://api.telegram.org/bot<TOKEN>/setWebhook" \
#     -H "Content-Type: application/json" \
#     -d '{"url": "https://golog-final.vercel.app/api/telegram/webhook"}'
